Apple Health Shortcut

      
    

    

      
Forged is a web app, and only native apps can write to Apple Health directly. A Shortcut you build once bridges the gap: Forged hands it your data and the Shortcut logs it.

      
Build the Shortcut (once)

      
    
        
  1. Open the Shortcuts app, tap +, and name it exactly Forged to Health.
    2. 
        
  2. Add Get Dictionary from Input. This reads what Forged sends.
    3. 
        
  3. Add Get Dictionary Value and set the key to weight.
    4. 
        
  4. Add If → Dictionary Value has any value.
    5. 
        
  5. Inside the If, add Log Health Sample: Type Weight, Value Dictionary Value, and the unit you use (lb or kg).
    6. 
        
  6. Optional: if your Shortcuts app has Log Workout, add it after the If and use the workoutStart and workoutEnd values (type: Traditional Strength Training).
    7. 
      

      
The first time it runs, iOS asks to allow Shortcuts to write to Health. After that, use Send to Apple Health after a workout or a weigh-in.

      
      
Full workout history

      
  1. Export workouts as CSV in Settings.
  2. Import the CSV into Strong or Hevy (both free).
  3. Turn on Apple Health in that app — it syncs your sets and workouts.
